STACKLY Charity Website

Open index.html to begin, or serve this folder with VS Code Live Server.
All 25 HTML pages, images, CSS and JavaScript are included.

External resources require internet: Google Fonts, Chart.js and the contact map.
Accounts, payments, event registrations and dashboard data are demonstrations.
Social links open platform homepages until official profile URLs are provided.

Edit assets/style.css for styles and assets/main.js for interactions.
